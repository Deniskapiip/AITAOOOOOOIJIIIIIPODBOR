# pc_parts

## Идентификация
Точная модель GPU/CPU/RAM/SSD, объём, частота, ревизия.
GPU: RTX 40/30, RX 7000/6000, производитель, TGP, длина.
CPU: сокет, поколение, TDP; RAM: DDR4/DDR5, частота, комплект.

## Обязательные проверки
- фото платы/чипов, серийный номер, наклейки;
- для GPU: температура под нагрузкой, артефакты, шум вентиляторов;
- для CPU: погнутые ножки/контакты, следы разгона;
- для RAM: парность комплекта, XMP/EXPO;
- гарантия, майнинг/ферма, ремонт, перепайка;
- доставка и упаковка (антистатик).

## Типичные обманы
Майнинговая GPU, перепаянная память, «новая» после прогрева,
подмена модели, CPU с погнутыми ногами, RAM без парности.

## Что просить на фото
Плата с двух сторон, серийник, GPU-Z/HWiNFO под нагрузкой,
CPU контакты, комплект RAM, упаковка.

самая дешёвая GPU часто после майнинга.
