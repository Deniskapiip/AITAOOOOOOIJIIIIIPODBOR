# Goofish Sourcing Agent v2

Автономный агент подбора б/у техники на Goofish (闲鱼) для Telegram.
Системный промт v2.0 (разделы 0–14), инструменты, лимиты вызовов и проверка
итогового JSON реализованы в этом репозитории.

Агент не покупает, не пишет продавцам и не гарантирует состояние товара.
Он собирает факты, считает цену для клиента и отдаёт менеджеру до 3 вариантов
с доказательствами и открытыми вопросами.

## Что умеет

- принимает запрос менеджера обычным текстом в Telegram;
- сам строит ключи, ищет, отсеивает аксессуары, ремонт, скупку и заглушки;
- проверяет карточки лотов, продавцов, отзывы и фото;
- считает итоговую цену только через calc_price (курс и комиссия из настроек);
- отклоняет небезопасный итог: больше 3 лотов, цена выше 105% бюджета,
  лот без карточки, «брать» без фото и чистых красных флагов, цена в тексте карточки;
- отдаёт JSON, карточки менеджера, ссылки и вопросы продавцу;
- пишет каждый прогон в data/runs для разбора.

## Быстрый старт

Требуется Node.js 20+ и ключ LLM (DeepSeek или любой OpenAI-совместимый API).

    npm install
    copy .env.example .env

Заполни в .env:

    TELEGRAM_BOT_TOKEN=...
    DEEPSEEK_API_KEY=...
    ADMIN_TELEGRAM_IDS=твой_telegram_id
    RATE_CNY_RUB=12.4

Затем:

    npm run doctor          # проверка настроек и сети
    npm start               # запуск Telegram-бота

В Telegram: /help, потом запрос одной строкой.

Пример запроса:

    Xiaomi 15 Ultra 16/512, до 60 000 ₽, только 国行, без ремонтов

Альтернативно курс задаётся командой администратора в боте:

    /rate 12.4
    /commission 6.5 650

## CLI без Telegram

    npm run agent -- "Xiaomi 15 Ultra 16/512 до 60 000 ₽, только 国行"
    npm run agent -- --json "..."          # только JSON
    npm run agent -- --rate 12.4 "..."     # курс на один прогон
    npm run agent -- --provider mock "..." # демо-данные

| ALLOWED_TELEGRAM_IDS | пусто | кому разрешён подбор; пусто = всем |

| RATE_CNY_RUB | не задан | стартовый курс; без него рублёвые поля null |
| COMMISSION_PERCENT | 6.5 | комиссия с цены телефона |
| COMMISSION_MIN_RUB | 650 | минимальная комиссия |
| GOOFISH_PROVIDER | mock | mock или http |
| GOOFISH_COOKIE | — | cookie залогиненного goofish.com для http |
| GOOFISH_PROXY_URL | — | прокси для Goofish (желательно китайский) |

| PHOTO_MODE | off | off или vision (нужна vision-модель) |

| LOG_LEVEL | info | debug/info/warn/error/silent |

## Лимиты

Всего 45 вызовов, включая finish:

| Этап | Лимит |
|---|---|
| calc_price | 2 |
| goofish_search | 9 |
| goofish_item | 15 |
| goofish_seller | 8 |
| goofish_reviews | 4 |
| view_images | 4 |
| finish | 1 |
| резерв | 2 |

Повторный запрос карточки или профиля отдаётся из кэша и не ходит в сеть.
Невалидный finish можно исправить и вызвать повторно (до 3 попыток, каждая
считается в общий лимит). Если лимит исчерпан, прогон завершается ошибкой без
выдуманного итога.

## Что проверяется на backend

- price_cny в итоге равен цене карточки, url строится из item_id;
- рублёвые поля берутся только из calc_price; без курса — везде null;
- лот в top обязан иметь карточку и статус «активно»;
- top ≤ 3 и ни один лот не дороже 105% бюджета;
- «брать» требует score ≥ 80, пустые red_flags, фото «ок», доставку и комплектность;
- score пересчитывается по score_breakdown, а не принимается на слово;
- факты о продавце (Zhima, продажи, регистрация) подтягиваются из профиля;
- медиана рынка считается по проверенным карточкам; если сопоставимых меньше 5,
  сравнение помечается как ограниченное и не штрафует лот;
- в card нельзя писать цену; карточка рендерится кодом;
- stats.tool_calls и stats.checked_deeply считает harness, а не модель.

## Реальные данные Goofish

По умолчанию включён GOOFISH_PROVIDER=mock: агент работает на демо-фикстурах,
чтобы можно было прогнать весь конвейер без аккаунта Goofish и без риска.

Режим http использует мобильный mtop API Goofish и требует:

- GOOFISH_COOKIE от залогиненного аккаунта (без него запросы отклоняются);
- желательно китайский прокси GOOFISH_PROXY_URL — с российского IP Goofish
  часто недоступен;
- калибровку нормализации: публичные методы и структура ответов меняются.

Для калибровки есть probe:

    npm run probe -- item 812345678901
    npm run probe -- seller s_a
    npm run probe -- reviews s_a
    npm run probe -- search "小米15 Ultra"

Сырой ответ сравнивается с src/goofish/normalize.js. Если Goofish изменил
поля, правится только нормализация, остальной агент не трогается.

Важно: это неофициальный доступ. Используй аккаунт, который не жалко, соблюдай
правила площадки и не пытайся обходить блокировки. Никто не гарантирует,
что Goofish не заблокирует аккаунт.

## Фото и vision

DeepSeek (deepseek-chat / flash / v4-pro) картинки не понимает: на image_url
он отвечает пустым сообщением, без ошибки. Поэтому PHOTO_MODE по умолчанию off:
фото не передаются, photo_check = «не проверялось», и вердикт «брать» невозможен.
Это защита от фантазий о состоянии экрана и батареи.

Если подключить vision-модель (Qwen-VL и подобные) через LLM_BASE_URL/LLM_MODEL,
поставь PHOTO_MODE=vision. При явной ошибке API движок сам сбрасывает просмотр
и требует «не проверялось».

## Ограничения

- агент не покупает и не проверяет товар физически;
- состояние подтверждается только карточкой, профилем, отзывами и фото;
- скриншоты утилит и заявления продавца не являются доказательством;
- при отсутствии курса итоговые рубли не считаются;
- доступ к реальному Goofish требует cookie и прокси, а его API нестабилен.
